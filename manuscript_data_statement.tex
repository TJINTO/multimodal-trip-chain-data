Detailed data preprocessing procedures, including the handling of missing observations, are documented on GitHub at \url{https://github.com/TJINTO/multimodal-trip-chain-data/blob/main/DATA_PREPROCESSING.md}.
The datasets are:
\begin{enumerate}
  \item Baltimore-MPO: 2017 annual-average-day person OD data for trips with car as the primary mode, using 597 traffic analysis zones in the selected study area (\url{https://www.baltometro.org/}).
  \item Chengdu-DIDI: demand and response point aggregates from 8--14 August 2016, aggregated into daily distributions over 734 grid units (\url{https://tianchi.aliyun.com/dataset/39384}).
  \item Shanghai-MetroFlow: station inflow and outflow data from 1 May--31 August 2017, covering 302 metro stations (\url{https://doi.org/10.6084/m9.figshare.28844942}).
  \item Philadelphia-SEPTA: Fall 2016 average-weekday bus boarding and alighting data, using 6,502 native bus stops in the selected inner-city study area (\url{https://catalog.data.gov/dataset/septa-ridership-statistics}).
\end{enumerate}
Generated Shanghai trip-chain samples are available in the same repository. Original datasets remain available through their respective providers.
